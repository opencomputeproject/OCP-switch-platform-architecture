# OCP-switch-platform-architecture

**A Unified Network Switch Platform Reference Design**

This repository hosts the *Open Switch Platform Architecture* (OSPA) specification, an Open Compute
Project (OCP) contribution that defines a vendor-neutral reference architecture for the **switch
platform management layer** — the hardware/software boundary that sits underneath the network
data and control planes.
